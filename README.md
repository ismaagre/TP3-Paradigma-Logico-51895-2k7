## Ejecución

Abrir SWI-Prolog y cargar el archivo correspondiente con:

```prolog
?- ['01_hechos_reglas.pl'].
```

Por ejemplo, para probar la suma de los primeros cinco números pares:

```prolog
?- suma(5, Resultado).
```

**Nota:** `suma/2` está definida de dos maneras para distintos ejercicios en los archivos 01 y 02. Cargar cada archivo por separado al probarlos.
